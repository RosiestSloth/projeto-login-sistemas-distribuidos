## Estrutura
- **/frontend**: Interface em HTML/JS puro que realiza chamadas HTTP via `fetch`.
- **/backend**: API em Node.js com Express que recebe e valida as credenciais.

## Como executar

### Backend
1. Navegue até a pasta `backend`.
2. Instale as dependências: `npm install`
3. Inicie o servidor: `npm start`
4. O servidor rodará em `http://localhost:3000`

### Frontend
1. Abra o arquivo `frontend/index.html` diretamente em seu navegador (ou utilize a extensão Live Server do VS Code).
2. Teste o formulário com as credenciais:
